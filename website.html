01 /Gli strumenti

Dal documento aperto
al lavoro finito.

Un editor per i PDF, uno per creare documenti. E gli strumenti di conversione e gestione che servono tra un passaggio e l'altro.

Pagine in ordine

Unisci più file, riordina le pagine, ruotale o estrai solo quelle che ti servono. Prepara il risultato prima di esportarlo.

Browser

Annotazioni e aggiunte

Aggiungi testo, immagini, note, evidenziazioni e collegamenti sopra le pagine. L'originale resta lo sfondo del documento.

Browser

Firme visive e moduli

Disegna o inserisci una firma visiva, compila i campi e crea moduli. Le firme visive non sono firme digitali certificate.

Browser

Dal foglio bianco

Scrivi con l'editor di documenti: stili, immagini, tabelle, intestazioni e numeri di pagina. Conserva la sorgente ed esporta il PDF.

Browser · motori server facoltativi

Testo e conversioni

Trasforma immagini in PDF, esporta le pagine come immagini ed estrai testo. L'OCR riconosce i testi delle scansioni; il server aggiunge la conversione Office.

Browser + server facoltativo

Protezione e dimensioni

Esporta una copia con oscuramento sicuro nel browser. Con gli strumenti server puoi aggiungere password, comprimere e verificare la struttura del PDF.

Browser + server facoltativo
02 /Dove avviene il lavoro

Sai dove vanno
i tuoi documenti.

Browser e server hanno ruoli distinti. Le capacità del sistema mostrano quali strumenti sono disponibili nella tua installazione.

01 — BROWSER

Il lavoro quotidiano resta qui.

Modifiche, annotazioni, pagine e progetti vengono elaborati sul tuo dispositivo. Aprire un file per questi strumenti non lo carica sul server.

Nessun database richiesto
02 — SERVER FACOLTATIVO

Più strumenti, quando li scegli.

Compressione, password, OCR server e conversione Office usano i programmi installati sul tuo server. Il documento viene inviato solo per l'operazione che richiedi.

Disponibilità e aiuto di installazione visibili

Le librerie del browser richiedono accesso alle CDN configurate. Il recupero automatico dipende dallo spazio del browser: scarica un progetto modificabile per conservare una copia indipendente.

05 /Prima di iniziare

Qualche risposta
utile.

I documenti vengono caricati online?

Gli strumenti browser elaborano il file sul tuo dispositivo. Se scegli uno strumento server, il file viene inviato alla tua installazione per quell'operazione. Le capacità del sistema indicano la distinzione.

Cosa serve per l'installazione?

Un server con PHP 7.2 o superiore e il file index.php. Non serve un database. I programmi server aggiuntivi sono facoltativi: il pannello delle capacità include i comandi di installazione per Ubuntu.

Posso cambiare il testo originale di un PDF?

L'editor aggiunge testo e oggetti sopra le pagine originali: non ridispone automaticamente il testo già presente. Per creare un nuovo documento impaginato usa l'editor di documenti.

Come posso riprendere il lavoro?

Scarica un progetto modificabile per conservare le tue modifiche. Il recupero automatico nel browser è un aiuto, non una copia di sicurezza: può richiedere i PDF originali e dipende dallo spazio disponibile.

Posso cambiare lingua durante il lavoro?

Sì. Italiano, inglese e tedesco sono disponibili sia qui sia nell'applicazione. La lingua dell'interfaccia può cambiare senza chiudere il documento o tradurre il suo contenuto.
